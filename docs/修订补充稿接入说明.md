# 修订补充稿接入说明

本轮依据《赤水行军图_集合版剧本_修订补充稿(1).pdf》21 页接入字幕断句、内心对白、六处转场和新增 11 段。用户已明确选择按史实和剧情时序校正新增内容。

## 字幕与阅读操作

五幕逻辑段落为 28、30、23、23、24 段，合计 128 段；实际拆成 249 个字幕框。每框最多 3 行，每行最多 16 字，优先在语义与标点边界拆分。短句允许少于 8 字，避免为了凑字数破坏语气。

保留原始段落 ID，分框采用 `A01-D001/a`、`A01-D001/b` 等显示键，避免与补充稿新增的 `A02-D011a` 等段落 ID 重名。用户界面不显示编号或剩余框数。点击第一次补全正在出现的文字，再次点击进入下一框；整段读完才推进下一段。

PDF 的“／”转为 750ms 停顿，逗号、顿号和冒号按 250ms 停顿处理；这些排练标记不直接印在玩家字幕上。换行只控制显示，不额外凭空插入口播停顿。内心字幕使用 85% 透明度，并在标题标明“内心”，不影响人物左右站位。A04-D020、D021 的“（心里）”统一改为“（内心）”。

补充稿附录与原稿有六处字词或标点差异，其中 A01-D006 少了“人的”。遵循其“不改原话”要求，现有 117 段保留原句，断行位置映射到原句；只统一两处内心标签。自动检查通过原文哈希确认无漏字。

## 六处转场

### 开幕独白（按后续界面反馈更新）

开幕独白改为三句繁体字，使用繁体明朝体／宋体字体栈及旧纸暖色。第 14 秒开始，三句分别以 0、1.8、3.6 秒延迟渐显，每句渐显 1.4 秒，已出现的句子保留。全部显示后，继续按钮用 0.9 秒渐显，完成后才接受点击或空格；一次继续进入第一幕前的转场。“跳過影像”直接开始三句渐显。按钮预留位置，避免出现时文字跳动。系统开启减少动态效果时取消渐显。

开场进入第一幕、四个幕间、第五幕进入复盘共六处。背景使用两层静态图叠化，时长 1.5 或 1.8 秒，配合极缓位移；字幕淡入后停留，2.5 秒后可点击继续。正文前仍保留此前要求的暗场幕序号和幕名。减少动态模式关闭位移与淡化。

转场文案按史实校正：一渡后先进入川南再辗转扎西，不写“过河就是云南”；遵义至鲁班场不压成次日直接抵达；茅台西渡至四渡保留“几天后”；尾声使用“五幕行军，走过那个春天”，不将四次渡河写成游戏里的“四天”。

`src/data/transitions.ts` 保存六处文案、美术提示与声音提示；`src/components/TransitionView.ts` 和 `src/immersive.css` 执行叠化。已有正式场景图会自动复用，缺图时继续显示 CSS 占位背景。BGM 在转场中连续播放并渐变音量。

环境音交叉淡化已接入 `src/audio.ts`，资源入口是 `ambientTracks`。六组正式环境音尚未交付，目前路径为 null，所以不会凭空出现真实的纸张、雨声、人声或炮声。配音也尚未接入，贴耳配音处理属于音频素材制作要求。

## 存档与尾声

继续沿用 `chishui-march-story-v3` 存储键，数据版本更新为 5。v3、v4 的下标先通过已发布版本的 ID 顺序转换；新版存储逻辑段落书签和段内框号，新增与重排不改变旧玩家的续读位置。原有攀登进度迁移规则继续有效。

复盘与尾声同步“西渡—东返—西渡—东返”口径；指导员信中“没问过一句为什么”改为承认青山问过且心里仍有疑问，以衔接新增对白。最终摆脱大规模围追堵截的叙述包含后续巧渡金沙江，不压缩为四渡当天的结果。

核对来源：[中央红军长征在贵州](https://www.dswxyjy.org.cn/n1/2026/0722/c244516-40765893.html)，中共贵州省委党史研究室，中央党史和文献研究院网站，2026-07-22。

原稿第五幕部分士兵对白含超出当下视角的敌军全局判断，以及 D017 的“往北，往西”，仍按保留原话原则保留，继续作为内容组待核项；新增内容未沿用其方向表述。
