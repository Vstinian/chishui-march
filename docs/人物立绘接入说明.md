## 表情如何变化

- `src/data/narrative.ts` 配置素材；`src/data/portraitCues.ts` 配置起始表情和 54 处段内转折，不修改剧本文字和字幕断行。
- 没有单独标注的对白沿用原剧本表情。情绪稳定的段落保持一张图；同段内由担忧转为期待、由训诫转为安慰等情况才切换。
- `at` 必须是该段原文中唯一出现的短语。当该短语的首字显示时开始切换。支持 `character` 指定在场倾听者的反应；未写时作用于说话者。
- 例如 A03-D020：指导员从宽慰开始，说到“明天”转为严肃，说到“水烧了”恢复宽慰。A03-D019 中小满听到“我可不敢回家”后，由开心转为忐忑。
- 表情跟随现有打字机显示进度，不按录音秒数单独计时。点击补全当前字幕框时，直接取该框结束的表情；减少动态模式直接显示完整文字及对应表情。
- 7 段保留第二字幕框的对白继续使用原分框。进入第二框时累计前框文字位置，读档恢复同样适用。打开菜单暂停文字与音频，关闭后接着当前进度播放。
- 表情替换只更新两层图片的透明度，交叉淡入 180 毫秒。图片解码完成后再切换，旧解码请求不会覆盖当前表情；减少动态模式关闭淡入。
- 同场景中，倾听者保留最近一次说话或反应后的表情；场景改变后重置。邓青山在左，当前交谈对象在右。50 段旁白继续显示背景全景。

## 半身构图与后续调整

`src/portraits.css` 控制构图。成年角色头顶对齐、对白框覆盖腰部以下；小满保留少年身高，原全身图使用 195% 图像高度，比最初接入时缩小约 13%，并下移人物区高度的 12%，头顶明显低于成年角色，三个表情保持同一比例。其余人物主要使用 155%–165% 图像高度。阿虎的背篓较宽，略偏移图片中心以保留脸部。没有镜像翻转，服装文字和装备方向保持原图。

手机允许人物轮廓自然交叠，说话者在前；画面只在整体边界裁切，不按人物格子截断肩膀。横屏根据对白高度压缩人物区，字幕保持可读。

修改表情时仅调整 `portraitCues.ts` 的短语或表情键；更换图片时更新 `narrative.ts` 的路径。新增伤员素材后可填 `wounded.portrait` 及 `expressions.tired`。运行 `npm run build` 和 `npm run smoke` 检查短语位置、素材路径、跨框与旧存档兼容。

本次保留 128 段正文、135 框字幕、音频编排和小游戏通关节点。A02-D011b、A04-D020、A04-D021、A05-D009c 继续保留未绑定配音状态。
