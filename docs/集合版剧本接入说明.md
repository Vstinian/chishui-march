# 集合版剧本接入说明（2026-10-14）

本文保留集合版首次接入记录。修订补充稿已将正文扩展为 128 段、249 框，新增六处文案叠化转场并迁移存档；当前规则及调整见 [修订补充稿接入说明](修订补充稿接入说明.md)。

2026-10-15 界面更新：正文铺满视口，顶部为透明的冲锋号声音图标与目录图标。每幕开始用约 3.8 秒暗场中央标题转场（减少动态模式静态显示 1.2 秒），进入后不显示左上角幕名。对话取消页码、史料和继续按钮，使用约 36 毫秒/字的打字效果；点击对话框先补全，再点击推进，空格和回车同样可用。史料札记改在每幕最后一段之后独立展示，确认后解锁并进入下一幕。v3 存档继续兼容，幕末额外下标用于恢复札记页。
