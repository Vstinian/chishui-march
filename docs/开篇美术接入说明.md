# 开篇美术接入说明

2026-10-21 已用《修改图.zip》替换一张完整旧报纸和四张赤水河开幕画面，尺寸均为 2730 × 1536。初版来自《开篇图(1).zip》。完整报纸为木桌俯拍，报头《赤水行军图》，副标题“艺术化叙事样报”，中央为山水插画；其余四图分别为水墨、雾气推进、上色和压暗版本。

## 文件位置

- 原始 PNG：`art-source/opening/`，原始命名映射见该目录的 README。
- 网页 WebP：`public/assets/opening/`，与 PNG 同名。
- 路径配置：`src/data/narrative.ts` 的 `openingArtwork`，使用 `assets/opening/…` 相对路径，兼容 GitHub Pages 仓库子路径。
- 渲染：`src/components/OpeningArt.ts`；动画：`src/immersive.css` 的 `opening-*` 关键帧。

当前修正版原图共28,636,182字节，网页资源共1,200,380字节，沿用最长边1600px、WebP质量83。原始PNG保留压缩包内原始字节，不进入 `dist/`。来源与哈希见 `art-source/opening/asset-manifest.json`，替换记录见 `docs/artwork-replacement-20261021.json`。

## 对应替换

首页使用完整报纸图替换原有 HTML/CSS 样报，移除原来叠加的排版与灰度滤镜。报纸完整显示，缩放时保持比例；“展开报纸 · 开始行军”仍为独立网页按钮。

开篇按以下顺序播放（2026-10-19 调整）：

1. `图片风格分析与AI生成词提取.png`：完整报纸，从出现起缓慢推进。
2. `赤水河雾气-推近帧(无中缝).png`：雾气推进。
3. `图片风格分析与AI生成词提取 (1).png`：水墨赤水河。
4. `赤水河-缓慢上色帧.png`：逐渐上色。
5. `赤水河-压暗收尾帧.png`：压暗收尾。

所有帧在进入开篇时加载，依次叠化。第 14 秒继续按现有节奏显示三句繁体独白，全部显示后再渐显“點擊繼續”；跳过影像、键盘和减少动态效果沿用现有逻辑。

进入第一幕前的转场复用压暗帧，替换原来的纯 CSS 报纸占位。手机上的报纸完整显示；山水段使用铺满视口的居中取景。

图内装饰性栏文不纳入剧本文字或史料札记，画面按本次交付原样使用。后续替换清晰版时可沿用这五个网页文件名。
