# 小游戏与存读档说明

2026-10-21 更新。五幕正文、字幕分框、场景图、互动插入段落、通关后的剧情与音频素材／编排保持现状。

## 五种玩法

| 幕 | 保留的基础任务 | 新增操作 |
| --- | --- | --- |
| 一：雨夜架桥 | 取门板，依次铺好三个桥位 | 对照桥桩跨度选择 1／2／3 格门板，必要时旋转，长度与方向均正确才铺稳 |
| 二：循声归队 | 在原 4×4 地图上逐格归队，原六步路线 | 用探杖探查相邻格，记录脚印与泥地；直接踩到泥地会退回当前实地 |
| 三：越过山口 | 六段，每段掩护→攀登→伏低→跟进，点错退一段 | 先看口令卡再合上行动；每段按钮排列交替，可随时重新查看口令 |
| 四：把战友带回掩体 | 先扶稳战友，分三段带回掩体 | 观察三个备选位置的遮挡与地面状况，选择能容纳两人的安全掩体 |
| 五：再向前一步 | 不出声走完八步浮桥 | 河风每步改变重心，用左右按钮调到中央安全区后迈步 |

- 任务没有倒计时，支持鼠标、触屏、Tab 与 Enter。错误不会改变剧情分支。
- 每个任务显示操作次数、调整次数与提示次数，不限次提示，不因失误扣除剧情资格。
- 原章末确认与章节解锁规则继续有效；已通关旧存档不会被要求补做新增操作。

## 游戏菜单

顶栏提供「存档」「读档」和三横杠菜单；Esc 打开／关闭菜单。开场影像与幕间转场需等待结束后使用。

菜单包含继续游戏、保存行程、读取行程、章节目录和返回首页。打开时暂停打字、人物配音、音效与配乐；关闭后继续原播放位置。菜单支持键盘焦点循环，背景不能误触。

## 存档规则

- **自动存档**：沿用 `chishui-march-story-v3` 键，数据版本升级为 6。正常剧情推进和小游戏操作后保存；进入首页、打开菜单不会改写自动记录。
- **手动存档**：三个独立槽位 `chishui-march-manual-v1-1` 至 `-3`。覆盖已有槽位前确认；读取前确认。
- **记录内容**：已解锁章节、段落 ID、字幕框号、小游戏步数、选中的门板／战友、门板方向、已探格子、记令阶段、地形观察、重心、操作统计，以及复盘节点。
- **恢复声音**：读档会停止旧轨道，按原编排从所存段落／字幕框重新触发配音、音效，并恢复适用 BGM；不保存音频播放秒数。菜单关闭则继续当前音频，不重播。
- **旧存档**：保留既有段落书签和通关进度，旧的未完成游戏可从原步数继续，新增辅助状态采用默认值。
- **重开**：新行程开始进入正文后更新自动记录，三个手动槽位保留。
- **浏览器存储**：存档仅限当前浏览器、当前网站地址，不是云存档。本地预览与正式网站各有独立记录；清理网站数据会删除。禁用存储／空间不足会显示保存失败，不伪报成功。
- **编排台预览**：禁用存读档操作，继续隔离正式游玩的存档。

本轮还以真实 Chrome 检查 390×844、1366×768、844×390 的交互与布局，实际验证菜单暂停所有音频、关闭不重复创建配音，以及读取后老雷 A01-D007 仍只有一道人声。
