# 网页音频压缩说明

2026-10-22，为 GitHub Pages 生成较小的网页音频。压缩对象为 `public/assets/audio/` 的发布副本；`audio/`、上传原件以及人物配音响度目标继续保留。

## 本次体积变化

单位 MB 为十进制 1,000,000 字节；不是首页一次性下载量。

| 类型 | 数量 | 压缩前 | 压缩后 | 减少 |
| --- | ---: | ---: | ---: | ---: |
| BGM | 11 | 101.39 MB | 28.29 MB | 72.1% |
| 音效 | 20 | 10.17 MB | 7.10 MB | 30.2% |
| 人物配音 | 78 | 17.04 MB | 8.52 MB | 50.0% |
| 合计 | 109 | 128.61 MB | 43.91 MB | 65.9% |

报纸开场《觉醒年代主题》由 9,368,386 字节变为 2,592,240 字节，约减少 72%。完整时长、循环和两秒渐强渐弱继续使用原编排。码率降低会损失部分音质；原件可用于将来重新导出。

## 导入和发布

`tools/audio-encoding.mjs` 统一编码：人物配音 64kbps 单声道，音乐和音效 96kbps 并保留输入声道，均为 44.1kHz MP3。去掉封面和非播放所需元数据。原始文件只作为输入，不被覆盖；归一化和编码每次都从原件开始，重复扫描复用同一处理规格的缓存。

`npm run audio:prepare` 扫描后迁移现有素材引用和独立开场曲。此次迁移 149 条编排，仅资源路径变化，音量、裁切、触发短语、字幕框和持续范围保持原值。没有运行会自动补齐配音的 `audio:voices`；A02-D011b、A04-D020、A04-D021、A05-D009c 继续未绑定。

新的文件名含源内容和编码规格哈希，浏览器会请求压缩后的新 URL。开发用 `public/assets/audio/` 保留历史版本以兼容旧草稿；`npm run build` 在 `dist/assets/audio/` 中排除历史文件，仅发布当前素材库和实际配置需要的文件。清理范围仅限构建目录，路径越界或缺失引用会使构建失败。

正式游戏继续按剧情加载当前配音／音效／BGM，并少量预取下一段配音；没有增加等待全部音频下载完成的步骤。实际首播速度还取决于 GitHub Pages 连接、浏览器缓存和播放器缓冲策略，不能把体积降幅当成固定的加载时间降幅。

## 校验与上线

- 全部声音绑定与压缩前对比，仅允许素材 URL 变化，保留原剧本指纹与四段未绑定状态。
- 人物编码时逐份测量成品响度及峰值，继续对齐 -20.5 LUFS。
- 构建与回归检查覆盖声音触发、范围音乐、菜单暂停、存读档、旧资源迁移和扫描缓存。
- GitHub Pages 的工作流只由 `main` 更新触发。推送素材分支后，需将该分支合入 `main` 并等待部署成功，正式网址才使用本次压缩版本。

逐素材大小、编码参数和引用检查记录在 `art-source/audio/web-compression-report.json`。
