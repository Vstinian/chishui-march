# 全局复盘接入与视觉交接（2026-10-13）

> 2026-10-14 更新：复盘正文已换为集合版的四个叙事节点，不再一节点对应一次渡河；第三节点“娄山关·遵义”关联二渡后的行动，第四节点关联三、四渡。原新华社链接保留作延伸阅读，新正文与数字仍待核。最新数据、素材接口与修改记录以 [集合版剧本接入说明](集合版剧本接入说明.md) 为准。下文保留此前设计与分工记录。

## 当前流程

首页 → 报纸开场 → 五幕叙事与小游戏 → 全局复盘 → 尾声。第五幕聚焦第四次夜渡的局部经历，读完收束对白后进入复盘；章节目录仅在五幕全部完成后解锁复盘。复盘用四个可切换节点，把玩家在行军途中看见的局部与战役全局放在同一屏对照。

本次复盘由本项目独立实现，未复制外部仓库的 React 组件、地图 SVG、样式、图片或历史文案。复盘路线是行动方向示意，不能当作地理坐标图。

## 参考项目的使用边界

- 参考仓库：<https://github.com/lengmodkx/sidu-red-river>。截至本次核查，仓库根目录和 README 未发现项目 LICENSE 或明确的改编、再发布授权。
- 如需复制其代码、美术或具体文字进入参赛作品，先取得作者书面许可，说明“修改后用于竞赛提交、公开演示及可能的获奖展示”，并按许可要求署名。
- 其技术栈为 React + Framer Motion；本项目是原生 TypeScript + CSS。即使获得授权，优先选取经核查的交互需求重新实现，避免把另一套运行框架嵌入主线。
- 参考项目时间轴将 `YYYYMMDD` 数字当作连续天数；播放每次推进不足 1 个数字又向下取整，日期会停住，跨月计算也不正确。其 README 的“73 天”与界面时间范围也不一致。这些内容不作为参赛作品的史实或程序依据。

## 已实现的视觉语言

复盘页已随沉浸版改成深暗红背景、米黄色纸张、暗红重点路线、宋体标题。地图面板保留纸张颗粒、地形线、赤水河与四段路线；选中节点加粗显示。图下明确标注“非真实坐标”。

视觉同学接手时，颜色覆盖在 `src/immersive.css` 的 `.recap-*` 规则中，结构样式在 `src/style.css`；需重绘地形时修改 `src/components/RecapView.ts` 的 SVG。请保持：

1. 整体与五幕场景共用色板，避免突然切回参考项目的白底军事信息图。
2. 四个渡河节点在 390 px 宽手机上仍可看清；按钮至少可稳定触控，文本不溢出。
3. 地图只表达东、西转向；若加入真实底图或具体渡口坐标，史实组需先逐点核查。
4. 自绘纹理、人物、图标记录作者或生成来源；不要搬运参考仓库的地图图层和图片。
