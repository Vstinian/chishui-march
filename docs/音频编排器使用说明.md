# 赤水行军图音频编排器

本机地址：`http://127.0.0.1:5175/audio-studio.html`。在项目目录运行 `npm run studio` 可启动并打开；已有5175服务时直接打开地址。游戏预览地址仍为 `http://127.0.0.1:5175/`。

## 当前剧本基线

编辑器直接读取当前运行项目的 `src/data/script.ts`。当前检查为128段正文，其中78段人物对白、50段独白；与团队此前确认的117段正文、71段对白的 `lines.js` 定稿统计不同。游戏与编排器均以实际运行的剧本和版本指纹为准，后续修改剧本时须一起核对录音。

配置记录剧本文字、段落ID和字幕分行的指纹。剧本变化时会阻止直接保存和正式播放不匹配的配置。核对每条绑定后，点击“确认当前版本的绑定”；此按钮只确认配置版本，不会改写剧本文字。

## 编辑操作

1. 左侧按幕筛选，或搜索人物、关键词与段落ID；点击任意段落，中间跳到真实游戏画面。
2. 右侧选择“人物配音”“环境与音效”或“背景音乐”，选择素材，点击“添加到这一段”。同一段可以绑定多个音效，并同时保留配音和音乐。
3. 选择触发方式：进入段落、进入指定字幕框，或打字显示到某个关键词末尾。重复关键词可指定第几次出现。
4. 分别设置片段音量、触发延迟、渐强渐弱时间、截取起止点、速度、循环与停止范围。截取终点0表示文件结尾。关键词按该段全部字幕匹配，忽略换行和空白。
5. 点击中间“从本段试听”。下方字幕框可以定位试听；也可暂停、继续、补全文字或推进下一框。竖屏选项用于查看手机裁切。
6. 右侧下方“三轨混音”控制总音量和三类声音；“配音期间音乐保留”越低，配音时音乐越轻。

当前已导入人物配音、环境音效及配乐。`A01-D001` 的风穿树林属于音效轨，另有独立的报纸开场曲及章节音乐。每条绑定的最新范围、裁切和音量均以 `public/audio/cues.json` 为准。

## 播放规则

### 报纸开场配乐

报纸开场使用 `audio/music/阿鲲 - 觉醒年代主题.mp3`，网页引用素材库中已导入的 `public/assets/audio/c157bb3a3a4f95be8874.mp3`。在 `src/data/narrative.ts` 的 `opening.bgm`、`opening.bgmVolume`、`opening.bgmFadeIn` 与 `opening.bgmFadeOut` 调整文件、音量及渐变时长。

玩家点击“展开报纸”后开始播放，2秒内从静音渐强，覆盖报纸动画、开场独白、幕前过渡及第一幕标题；第一幕正文出现前的最后2秒渐弱到静音，随后交给章节音乐。减少动态模式也会保留完整的2秒渐弱。等待期间循环，跳过影像不会中断；静音开关与切换后台均生效，重新开始会从曲首播放。开场曲不受编排器中章节音乐的启用状态影响。

### 让雨声、配乐覆盖连续多段

1. 在**起始段落**添加一次音效或音乐，设置原有的开始时机（进入段落、字幕框或关键词）。中间各段不必重复添加同一个声音。
2. 将“声音持续范围”设为 **指定连续段落（跨段播放）**，选择同一幕中较后的“结束段落”。列表遵循真实剧本顺序，不能只看 ID 数字大小。
3. 结束方式选“读完结束段落，离开时渐弱”，声音就会覆盖结束段落的全部字幕；也可以选“结束段落的关键词出现时渐弱”，填写关键词及第几次出现。
4. 持续雨声、长段配乐建议勾选 **循环播放**。否则文件播完就结束，范围设置不会自动延长文件。渐强只用于开始播放，循环接续不会每轮重新渐强；渐弱从剧情终点触发时开始计时。
5. 例如：在 `A01-D002` 添加雨声，范围结束设为 `A01-D004`、离开时渐弱、循环开启、渐弱 2 秒。雨声会连续覆盖 D002、D003、D004，进入下一段时渐弱退出。
6. 左侧“延续 N”及右侧“来自某段”标识该段被哪些声音范围覆盖。点击右侧延续音轨可以回起点编辑、试听；中间“正在播放”才是实际播放状态。直接跳到范围中间或从存档续读，会从截取起点恢复覆盖该处的最后一条跨段/整幕背景音乐；不会重播之前的配音、枪声等音效。要检查精确触发时机及环境音的连续性，仍应从绑定起点推进。

范围支持同一幕内的相邻对白，跨幕需重新绑定。进入小游戏、转场、札记仍会清理音频。新的音乐绑定会接替旧音乐，叠加的音效各自独立；因此不要在覆盖范围内每段重复添加同一首配乐。已有段落/字幕框/整幕绑定继续有效。

- 配音、音效和音乐共用同一触发引擎，参数独立；多个音效可叠加，配音及音乐各保留一条主轨，新片段接替同轨旧片段，可通过渐强渐弱交叉过渡。
- 第一次点击补全字幕，尚未出现的关键词会在补全时触发；第二次点击推进。重复渲染、保存和开关目录不会重复启动已触发的片段。
- 声音可在离开字幕框、段落、指定结束段落或当前幕时停止，也可在结束段落的关键词出现时渐弱。打开目录和切换到后台暂停；进入小游戏、转场、札记或离开游戏时清理绑定音频，避免串音。
- 编辑参数会更新预览；更换触发点、裁切等参数后请从本段重新试听。原素材试听用于选材，按“停止试听”结束。
- 首次打开不自动发声，需要点击试听或选择对白；浏览器拒绝音频时会显示提示，游戏仍可继续。预览使用独立进度，不写入玩家存档。

## 文件写回和协作

- “自动保存”默认开启，合法修改停顿约0.8秒后写入 `public/audio/cues.json`；也可点击“保存到项目”。顶部显示保存成功时间或错误，不能仅凭右侧参数变化判断已经落盘。
- 写回只在本机 Vite 开发服务中有效。GitHub Pages等静态正式站可读取配置与播放，但不能直接修改你电脑上的文件。
- 每次保存先保留上一版到 `art-source/audio/cues.previous.json`。其他窗口或成员已修改项目文件时拒绝覆盖，提示先导出草稿再重新读取。
- 支持撤销、重做、导出/导入JSON和恢复本地未保存草稿。刷新恢复以项目文件为准；尚未成功保存的改动先导出备份。
- 袁艺航负责素材导入与编排；张郑卓丹负责运行剧本、程序整合和发布；张子含校对字幕、关键词及来源；周徽音确认听感与配音表现。同一时间由一人负责保存配置JSON，其余人通过预览和清单反馈。
- 保存到项目后，还需把配置和新增网页音频提交到GitHub，合并并部署，正式链接才会更新。

## 素材导入和压缩

素材库可以导入MP3、WAV、OGG、M4A，单文件上限64MB；也可以扫描项目根目录的 `audio/`。网页文件存入 `public/assets/audio/`，清单保存到 `public/audio/library.json`，使用内容哈希命名以避免中文路径、重名和缓存混淆。界面保留原始文件名及常用音效中文提示。

根目录 `audio/` 文件完整保留；界面上传的源文件保存到 `art-source/audio/`。WAV在FFmpeg可用时自动转换为44.1kHz、128kbps MP3；当前电脑已配置工作区内的FFmpeg。其他电脑可安装FFmpeg并放入PATH，或设置 `FFMPEG_PATH`；本机 `audio-tools.local` 也可配置 `ffmpeg` 路径，该文件被Git忽略。无FFmpeg时保留WAV并提示发布前压缩。

命令行扫描：`npm run audio:prepare`。8个现有WAV合计51,337,382字节，生成MP3合计3,916,146字节，减少约92.4%。上传新配音时仍应试听音质与首尾完整性。张子含需补齐下载素材作者、来源网址和许可记录。

### 替换已有配音

将新版文件覆盖到 `audio/` 下的**同一路径和文件名**，再点击“扫描项目 audio 文件夹”。扫描会重新生成内容哈希不同的网页音频，同一源文件在素材库中只显示当前版本，并把引用旧版的编排绑定切到新版；音量、字幕框、关键词、延迟及裁切参数保持原样。扫描完成后点击“从本段试听”。关闭自动保存时需手动保存，正式站还需提交新音频、素材清单与编排配置并重新部署。

`npm run audio:prepare` 同样会更新已有绑定。命令行扫描后，已打开的编排器应“重新读取项目”以获取新版本；如有未保存修改，先导出草稿。旧网页音频保留在磁盘供撤销或回退，不会继续列为同一源文件的另一个同名素材。换成不同文件名或目录视为新增素材，不会替换原来的绑定。新版配音如改变了开头留白或句子长度，应重新试听检查裁切点。

### 人物配音响度与按编号绑定

运行 `npm run audio:voices`，以当前老雷 `A01-D007` 为参考测量响度，再处理所有 `audio/voice/` 下的人物录音。原始 WAV 保留，仅生成网页播放版本；处理后的人声响度实测误差不超过约 0.5 LU，配音片段音量统一沿用参考段。当前基准为约 -20.5 LUFS。配置位于 `art-source/audio/voice-levels.json`，逐段测量与绑定结果见 `art-source/audio/voice-level-report.json`。以后扫描会沿用这一基准，重复扫描复用已处理的网页文件。

自动绑定同时核对文件名中的完整段落 ID 和角色文件夹，补齐已有录音尚未绑定的对白；已有字幕触发及裁切设置保留，新绑定默认进入段落时完整播放一次。误放到音效轨的同段人物录音重复项会移除。人物素材通过“添加到这一段”自动归入配音轨，同段同素材不再重复添加；试听原素材会先停止剧情预览的声音，避免同时播放两份人声。

## 验证与限制

运行 `npm run smoke` 和 `npm run build`。本次验证包括完整通关、关键词触发、播放去重、暂停恢复、延迟取消、跨段音乐、跨幕渐弱、三轨混音、剧本指纹；浏览器验证了三栏选择、三轨同时播放、自动保存到磁盘、刷新保留、存档隔离与冲突拒绝。

这是本地音频编排demo。已实现触发和音量包络，尚无波形拖拽、逐字强制对齐、自动配音生成或多人实时协同。滑块反映音量设定，不是实际响度或频谱检测。续读会重启当前覆盖的背景音乐，不保存音乐的秒数；要验证精确触发与接续，应从绑定起点连续播放。
