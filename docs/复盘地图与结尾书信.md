# 复盘地图与结尾书信

## 参考与素材来源

- 地图参考用户提供的 `sidu-red-river-master.zip`，用户已说明获得原作者许可。参考文件：`src/components/Map.tsx`、`MasterMap.tsx`、`src/data/places.ts`。沿用分层山川、阶段箭头、地点标记的呈现思路，以原生 SVG/CSS 为手机重新绘制；没有引入参考项目的 React、Framer Motion 或 node_modules。
- 原有四个叙事节点和历史说明保留。第三个节点突出娄山关、遵义；第四个节点同时呈现三渡与四渡。图上距离、河流、地点为排布示意，不作实测地图使用。
- 手写字体采用 [Ma Shan Zheng](https://github.com/google/fonts/tree/main/ofl/mashanzheng)，Copyright 2018 The Ma Shan Zheng Project Authors，SIL Open Font License 1.1。完整许可保存在 `public/assets/fonts/MaShanZheng-OFL.txt`。
- 字体下载后在本地用 FontTools 裁剪为 WOFF2，仅保留结尾文字所需的 189 个字符，约 68 KB。网页从本站加载字体，不请求外部字体服务。字符清单为 `public/assets/fonts/letter-characters.txt`。今后改信件时，新增字符需更新字体子集，否则会使用楷体后备字体。

## 交互与排版

- 手机剧情画面及字幕框左右贴边，框内仍保留阅读内边距和屏幕安全区。复盘地图适配屏幕宽度，不再要求横向滑动看全图。
- 地图下方渡河按钮、右侧（手机为下方）叙事节点按钮均可切换高亮路线；提供上一个、下一个节点。减少动态模式关闭描线动画。
- 信封使用原生 `details/summary`：点击、回车或空格均可拆开或收起。展开时翻起封口、展开信纸；减少动态模式直接显示。开关菜单不会收起已展开的信纸，再次进入尾声或读档时从信封开始。
- 信件正文保留原文，称呼顶格、正文首行缩进两字；末尾补上原信标题已有的署名与时间地点，右对齐。

## 字幕与音频

- 仅清理显示层非动作类括号提示，如“内心”“带哭腔”“气声”“沙哑”“虚弱”“等不及”和位置说明。
- 保留“回过头”“上前一步”“边走边问”“传口令”“喘息”“沉默一会儿”“凑过来看水缸”“看了一眼天上的飞机”“在前头回头”等动作。
- `subtitlePresentation` 返回显示文字及原文字位置映射。打字进度映射回原文后再传给音频引擎和表情系统，因此配音、关键词、跨段音乐、表情触发、受保护的第二字幕框和旧存档定位不变。
- 七个保留双框的段落（A01-D008、D014、D015、D018、D021，A02-D011a，A04-D016）在每一框内部合并成连续一段，按屏幕宽度自然换行。原本两框之间的切换位置、框号及声音绑定继续保留。
- 共检查 128 段正文、135 个字幕框，其中 12 框的显示文字经过清理。`npm run smoke` 包含位置映射与动作提示保留检查。
